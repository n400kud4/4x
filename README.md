# 4x Player

語学教材や講義音源を 0.5×〜4× の可変速で聴くためのシンプルな Web プレイヤー。
iPad の「ホーム画面に追加」で PWA としてフルスクリーン起動・オフライン動作・ロック画面操作に対応。
音源はブラウザ内で完結し、サーバーには一切送信されません。

## 使い方

1. ドロップゾーンをタップしてファイルを選択、またはファイルをドロップ（複数同時OK）
2. プレイリストから曲をタップ、または ▶ で先頭から再生
3. SPEED スライダーで 0.5×〜4.0× を調整。`1×` `2×` `4×` プリセットボタンあり
4. 「ピッチ保持」ON で倍速再生中も声が高くならず聞き取りやすい
5. LOOP ボタンで `OFF → ONE（1曲リピート）→ ALL（全曲リピート）` を切替

## キーボードショートカット

| キー | 動作 |
|---|---|
| `Space` | 再生 / 一時停止 |
| `←` / `→` | 5秒シーク |
| `Shift+←` / `Shift+→` | 前 / 次のトラック |

## iPad「ホーム画面に追加」手順

1. iPad の **Safari** で本アプリの URL を開く
2. 画面上部または下部の **共有ボタン**（□ から ↑ が出るアイコン）をタップ
3. 表示されたメニューを下にスクロールし、**「ホーム画面に追加」** をタップ
4. 右上の **「追加」** をタップして完了
5. 以降、ホーム画面のアイコンから全画面（アドレスバーなし）で起動できます
6. 一度オンラインで開いておけば、機内モードでも起動できます（音源ファイルは別途必要）
